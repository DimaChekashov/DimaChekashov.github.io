# Warum statisch?

Für Portfolio- und Inhaltsseiten ist ein statischer Ansatz oft die beste Wahl.

## Vorteile

- keine Datenbank
- kein Backend für Beiträge
- schneller Deploy

## Ablauf

1. Neue Datei `README.md` anlegen.
2. Änderungen pushen.
3. Deployment läuft automatisch.
