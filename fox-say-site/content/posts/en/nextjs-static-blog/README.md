# Why static works well

For content-focused sites, static generation keeps your stack simple and reliable.

## Benefits

- no database
- no server-side auth flow
- easy CI/CD deployment

## Workflow

1. Add a new `README.md` file.
2. Commit and push.
3. Let GitHub Actions publish the site.
