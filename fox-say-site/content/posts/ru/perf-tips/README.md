# Базовый чеклист

Перед сложными оптимизациями стоит закрыть базовые вещи.

## Что проверить

- размер JS-бандла
- количество ререндеров
- lazy loading для тяжёлых блоков
- корректные размеры изображений
- кэширование статических ассетов

## Вывод

Сначала измеряй, потом оптимизируй.
